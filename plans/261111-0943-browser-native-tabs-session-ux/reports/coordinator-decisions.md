## Required behavior
1. Horizontal native-style tab strip above compact navigation/address bar; stable tab order/active selection; add/select/close tabs, title fallback, explicit close, horizontal overflow, keyboard ARIA tab navigation. In-tab New Tab page rather than entire-window chooser. Last tab close leaves a blank New Tab, not a destroyed OS window.
2. App reload/network reconnect: reconnect exact existing live backend sessions; no navigation/recreation of live pages, preserving remote DOM/history/form state. Server/Chromium restart or missing target: retain address, show unavailable with explicit Reload; never silently POST new targets.
3. Explicit OS Browser-window close: save only restorable committed addresses, order and active index for the most-recently-closed window of its owner scope; close its live targets (respect other same-client views of shared target), not Chromium credentials. Default reopen with no existing Browser window restores that saved group into fresh pages, lazily as selected within configured capacity. This is an explicit user reopen exception, not automatic server-restart restoration. Explicit New Window and recipe/deep-link URL launches must not unexpectedly restore another group. Failed close must retain reconciliation state and not claim success or create duplicate target while outcome unknown.
4. Hidden tabs keep remote pages alive; pause streamed video AND audio, release input control/held keys. No background audio, LRU discard, raising target/viewer budgets or new backend registry. Capacity errors leave useful placeholder tab/address and allow explicit retry; explain popup competes for same budget.
5. Popup OAuth appears as adjacent linked tab without overwriting opener. Auto-select newly admitted popup once; popup completion returns to opener only if user still views that popup, never steal focus from another tab/window. Do not auto-reopen/serialize popup authentication URLs.
6. Address editing: per-tab in-memory drafts survive local tab switching and placement, not persisted or logged. Server snapshots update committed URL without clobbering dirty editing draft. Enter commits validated URL once, Escape restores current committed URL; preserve CAS single-flight and no replay after 409. Scheme-less host/port convenience may be normalized using existing policy, no external search provider or query search.
7. Stable windowId/tabId/backend sessionId/viewer identity separation; root host keyed by window+tab for resource continuity; inactive tabs have zero streaming viewer attachments. Switching back may mint fresh socket tickets but MUST NOT create/reload native target; placement transitions retain canvas/controller identity. Preserve current privacy/reset/audio/selection fences.
8. Keep cookie/login storage solely in server-owned Chromium profile; no cookie/session credential export. Sanitize OS save/import/export and recipes with one current model; one-time legacy single-tab input conversion, no perpetual top-level alias/shim. Runtime authority never serialized.
9. Owner scope must include profileId, normalized endpoint AND authenticated principal (not profileId alone). Current ConnectionSnapshot lacks user identity (`connections.ts:91-100`); `checkAuthStatus` already returns server-verified `user` (`auth-client.ts:454-457`), checked in connect flow (`connections.ts:449-479`) then discarded. Expose existing verified user in connection snapshot as needed; no JWT decoding or trusting editable profile username. Clear/withhold identity on disconnect/logout/replacement; fail closed if unknown. Development namespace must remain distinct. Check actual auth status type and dev flags during authoring.
10. Avoid persisting auth-popup URLs; committed ordinary URL persistence is local plaintext metadata, potentially sensitive (query/path); document this and offer an existing/local clear remembered-pages affordance. No third-party favicons or URL forwarding/search. Use generic existing Lucide page/globe icon rather than new favicon backend/CDP scope. Do not invent page-load percentage, TLS/secure lock verdict or canGoBack metadata unavailable in DTO. Buttons remain honest pending/error states.
11. Existing non-browser features unchanged; no engine/native host replacement, new DB, dependencies, bookmarks/download/password/history managers, tab groups/pinning/drag-out, or reserved outer-browser shortcut guarantees. Use visible actions and scoped tablist arrows/Home/End/Delete; no speculative global shortcut mapping.
