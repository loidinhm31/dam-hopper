### Provisional Retention & Undo Budget Policy for Phase 02 (`C2`)
- **Per-document undo stack bounds (enforced via `enforceUndoBounds()`)**:
  - Normal tier (`< 1 MiB`): `maxUndoStackSize = 200` actions AND enforced `maxUndoBytes = 2 MiB` logical UTF-16 undo payload (`JavaLanguage` syntax highlighting for supported extensions, `EmptyLanguage` for unknown extensions).
  - Degraded editable tier (`1 MiB .. < 5 MiB`): `maxUndoStackSize = 50` actions AND enforced `maxUndoBytes = 2 MiB` logical UTF-16 undo payload, `EmptyLanguage()` plain-text mode, `basicDisplayMode = true`, `highlightBracketPair = false`, auto-complete disabled.
- **Aggregate workspace retention budget (provisional until Phase 08 mounted-device profiling)**:
  - Observed retained heap for an unmounted `Content` instance is `~3.2x` its UTF-8 byte length (`~3.15 MiB` for `1.04 MiB` UTF-8; `~15.18 MiB` for `5.07 MiB` UTF-8), and `ByteArrayOutputStream.toByteArray()` transiently holds both its internal buffer and the returned `ByteArray` (`~2x` snapshot bytes at allocation peak).
  - Define each live document's conservative provisional accounted memory cost in Phase 02 `EditorDocument` / `EditorSessionPorts`:
    `estimatedRetainedBytes(doc) = (doc.utf8Length * 4L) + doc.undoStackBytes + (doc.inFlightSnapshotBytes * 2L)`.
  - Cap aggregate workspace `sum(estimatedRetainedBytes(doc))` at `64 MiB` (with hard instance caps of at most `8` live retained `Content` documents and at most `2` simultaneous degraded `1..5 MiB` documents).
  - When opening a new file would exceed budget, evict clean inactive documents via `doc.close()` (retaining lightweight tab metadata/view-state for reload on focus) or refuse open with actionable notice when all open documents are dirty/in-flight; never silently evict dirty or unresolved-save documents.
