## 5. Coverage Caveats & Scope Limitations

1. **Synthetic Mock Server**: `TestToolchain` uses `lsp-test-server.mjs` fixture and mock `tsserver.js`. Real bundled TypeScript Language Server qualification is deferred to Phase 09.
2. **Assertion Depth**: Multi-connection and document-close tests assert session state and overlay byte totals, not full end-to-end AST navigation resolution from competing dirty buffers.
3. **Adaptive Sync Wire Format**: Sync crossing test validates recommendation state in overlay map, not the serialization of UTF-16 incremental frames over stdin FIFO.
4. **Destination Freshness**: Version extension fence validates stale version rejection on incoming navigation calls; destination snapshot validation during in-flight mutations remains for Gateway integration (Phase 05).
5. **Admission Concurrency**: Concurrency limits tested sequentially; multithreaded contention and abort races unexercised.
