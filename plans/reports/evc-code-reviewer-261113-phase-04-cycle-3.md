## Warnings

### C3-W1 — High: fresh-audio authority still not atomic end to end
- **Sample precedes gate lock:** `server/src/browser_host/screencast.rs:777-801,1007-1009` reads latest sequence before acquiring adaptive state. Audio increments/broadcasts independently (`:2219-2237`). Interleaving: sample N; broadcast N+1 while suppressed; reopen with watermark N; dequeue N+1 under new generation. **[INFERENCE]** Old audio can pass the new boundary; no deterministic full-server delivery reproduction performed.
- **Generation belongs to a shared atomic, not the queued chunk:** `server/src/browser_host/media.rs:1563-1578,1865-1867`; `media_writer.rs:87-90,109-116,417-420`. After writer takes an old slot but before its check, recovery plus admission of a fresh chunk can overwrite `queued_audio_gen`. Old slot then checks against the fresh generation. **[INFERENCE]** This defeats the generation fence despite the admission watermark.
- **Expiry recovery misses the edge:** `adaptive_stream_controller.rs:160-185,391-393,503-509`. Read-time expiry suppresses audio without synchronizing `gate_suppressed`; report overwrites `last_report` before synchronizing. **Observed source-derived Rust probe:** allowed/gen3/watermark99 → expired Hidden → report with latest200 → Allowed/gen3/watermark99. Reopen neither changes generation nor records watermark200.
- **Source reset remains scalar:** `screencast.rs:1018-1026` resets `audio_seq` to zero; viewer watermark (`adaptive_stream_controller.rs:137`) contains no source identity/reset. **[INFERENCE]** A retained subscription with watermark N can suppress a genuine new source's first N chunks. No same-subscription source-restart qualification found.
- Correction: synchronize source/sequence boundary with actual reopening; synchronize old time-derived closure before report mutation; carry admitted generation/sequence with each writer slot and validate that slot, not a separately overwritten atomic; source-scope/reset the watermark. Confidence: high for source defects; actual race delivery remains unmeasured.

**Mute acknowledgement assessment:** no new audio-after-ack path established while gate remains closed. Mute closes gate and clears audio before enqueueing status (`media.rs:2031-2045`); write-time gate check remains (`:1207-1219`); the single writer finishes any in-flight audio before writing its acknowledgement (`media_writer.rs:385-467`). Per-viewer state remains subscription-keyed; the Rust probe left sibling generation unchanged. Parsing overflow/invalid sequence becomes zero and is rejected (`media.rs:1861-1863`); envelope validation rechecks canonical positive u64 (`media_writer.rs:81-85`, `protocol.rs:1037-1039`). Producer sequence increment is checked, not wrapping (`screencast.rs:2219-2223`; boundary regression `:3758-3764`).

### C3-W2 — High: FPS convergence creates a later version rollback; run placeholders erase fences

Confidence: high; projection and controller boundary reproduced, not a live shaped-link journey.
