## High-priority findings

### F1 — P1: Retained clean models can overwrite accepted external changes
- Location: `packages/ui/src/components/organisms/MonacoHost.tsx:617`.
- Clean reload sets loading (`editor.ts:1201-1205`), unmounting MonacoHost (`EditorTabs.tsx:646-650`), but `keepCurrentModel` preserves its old text. Reload accepts new disk content and mtime (`editor.ts:1244-1254`). The pinned React wrapper reuses the old model on remount and skips its value effect on initial mount; mount code does not reconcile accepted text.
- A subsequent edit puts old-model text into the store; save uses the newly accepted mtime (`editor.ts:921-928,947-964`), permitting replacement of external changes without an mtime conflict.
- Correction: reconcile accepted clean reloads into retained models/overlays; preserve genuinely dirty reconnect/undo state.
- Evidence: conclusive static component/store/wrapper chain; full browser edit→save overwrite not exercised.

### F2 — P1: Normal Linux publisher omits the bundled engine
- Location: `deploy/release/build-release-archive.sh:223-226`.
- Engine inclusion is opt-in; `.github/workflows/release-linux.yml:201-210` and `tests/deploy/linux-release-package-twice.sh:69-76` supply neither staging nor engine directory. Fresh release-local enablement therefore lacks its required toolchain.
- Correction: verified engine provisioning in the publisher, passed to both deterministic archive builds; require essential engine inventory for server-capable releases. Staging defaults must not rely on developer-local paths.
- Evidence: static publisher→builder chain plus runtime builder probe showing zero engine entries. Probe used placeholder executable scripts/web HTML: verifies packaging branching only, not a real published release or installed enablement failure.

### F3 — P1: Requery coordinates can be relabeled with newer destination proof
- Location: `server/src/semantic/gateway.rs:1944-1951`.
- Interleaving: destination absent at initial submission becomes user-open at A before pin; requery computes coordinates against A; after `docs_after_requery` capture, destination changes to B; awaited live snapshot B replaces provenance while `final_raw_result` retains A coordinates. Cached before/after maps pass; later validation checks membership/range bounds, not equality with immutable query proof.
- Matching B SHA/version can then satisfy client destination checks while revealing A's stale coordinates, if still in bounds.
- Correction: retain `_damHopperProvenSnapshots` from the exact requery; reject identity/version changes rather than refreshing proof from live text.
- Evidence: static actor→gateway→client chain; deterministic concurrent interleaving not exercised.

### F4 — P1: Git mutations bypass new protected-config boundary
- Location: `server/src/api/git.rs:453-459`.
- Deployment condition: canonical global config is under a registered linked worktree, e.g. `XDG_CONFIG_HOME` configured there; target is unlocked/non-main and has no live PTY. Ordinary authenticated User may force-remove it. Route and Git CLI sink do not consult the new canonical containing-directory protection. Tracked config can also be replaced via ordinary discard (`api/git_diff.rs:187-202` → `git/diff.rs:737-746`).
- Impact: durable semantic intent/global settings can be removed/restored outside fresh-admin settings transaction; not a claim of immediate runtime enable/disable or arbitrary deployment exposure.
- Correction: enforce protected-object identity at Git worktree-writing/removal boundaries without restricting unrelated Git operations.
- Evidence: static authorization→target validation→Git mutation chain; isolated API exploit not exercised.

### F7 — P2: Raw-file proof disagrees with decoded/normalized Monaco content
- Location: `packages/ui/src/components/organisms/MonacoHost.tsx:244-246`.

- Correction: one explicit coordinate-bearing representation across pin/query/sync/proof; do not normalize only the digest and leave mismatched coordinates.
- Evidence: BOM digest inequality reproduced; reveal failure follows static comparison. Actual browser reveal and mixed-EOL normalization were not exercised.

### F8 — P2: CR-only documents reject valid coordinates
- Locations: `server/src/semantic/uri.rs:462-465`; `server/src/semantic/overlay.rs:48-52`.
- Pinned TS recognizes standalone CR line breaks; LF-only Rust splitting rejects later-line locations/edits. Valid definitions can be filtered out.
- Correction: shared lossless LF/CRLF/CR line handling preserving UTF-16 and byte offsets.
- Evidence: production Rust helper probe accepts LF/CRLF line 1 but rejects CR-only line 1 in both range and offset helpers; end-to-end CR navigation not exercised.

### F9 — P2: Second navigation stage loses cancellation ownership
- Location: `server/src/semantic/gateway.rs:1533-1540`.
- Client/internal mappings are removed after first child reply, before pin-and-requery. Second internal request is not mapped back to the logical client request; cancellation cannot find it, and same-ID reuse can be admitted before terminal response.
- Correction: retain logical registration/token through both stages; update active child ID, reject reuse, release only at terminal completion.
- Evidence: static mapping/requery/cancel chain; cancellation interleaving not exercised.

### F10 — P2: New document revives exhausted child without overlay replay
- Location: `server/src/semantic/session.rs:1083-1084`.

- Correction: one budgeted recovery/replay barrier or terminal rejection requiring a fresh session; preserve initial lazy startup.
- Evidence: production actor/real Node fixture probe exhausted two automatic restarts, then didOpen(B) spawned child 4. Actor retained A+B; child request inspection/event log showed only B, no A replay. Actor boundary reproduced; not real TSLS/WebSocket qualification.

### F11 — P2: Empty initialized sessions never arm idle eviction
- Location: `server/src/semantic/session.rs:1049-1051`.
- Initialize transitions Ready without scheduling the zero-document/zero-request timer. Two initialized sockets kept alive without opening documents can hold both global slots beyond the promised 60-second idle bound.

Open→close positive control evicted/reaped at 63 seconds. Actor boundary reproduced; WebSocket/Ping integration remains untested.

### F13 — P2: Semantic upgrade auth lacks the documented store deadline
- Location: `server/src/api/semantic_ws.rs:260`.
