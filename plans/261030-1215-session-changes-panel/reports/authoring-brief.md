## Architecture decisions to elaborate, not replace
- Dedicated `server/src/session_changes/` domain (Rust snake_case), not HEAD/index diff adaptation or source in semantic status. Own private out-of-worktree TempDir and bounded manifest/content; reuse fs::secure_path::read_regular_snapshot and canonical VCS-root resolver. No DB schema or production dependency needed. Baseline reads actual bytes, raw byte equality; no git filters/normalization or user-index writes. Symlinks/gitlinks/special paths explicit unsupported; no follow. Inventory tracked + nonignored untracked; union original manifest and fresh eligible paths so staging/commits do not erase changes. Original missing is known absent only when complete inventory proves it; excluded/truncated inventory is unknown, never fabricated addition/deletion/zero.
- One domain service shared via Arc between AppState and existing private collector. PTY canonical target binding authoritative. Agent bearer derives terminal/incarnation; never browser-selected target for producer authority. Account authentication remains existing server policy, not invented per-user PTY ACL. Bind exact OMP session ID and canonical root, separate browser profile/generation fences. Full terminal target must be server-validated (configured/worktree/free terminal sandbox semantics require exact evidence).
- Private authenticated bounded HTTP registration/readiness and settled-turn controls on EXISTING loopback collector listener, distinct from status WS frames; derive HTTP URL from injected collector URL, no new env/port/daemon. Public authenticated `/api/terminal/{id}/session-changes/...` status, explicit from-now registration, comparison refresh/list/detail. Final exact endpoints/DTOs/errors in contracts before concurrent work. Source bytes only public authenticated read endpoints with private no-store caching.
- Readiness: async root-interactive session_start/session_switch before first prompt; before_agent_start checks same identity/failure state, not recapture. Installed runner 30s fail-open. Proposed exact default producer capture request deadline 10s, adapter wait 12s (<30s). A request carries unique registration ID and same-host absolute expiry; server rejects already-expired delayed arrival, clamps future expiry, converts accepted budget to monotonic deadline and checks it before all publication. Deadline expiration invalidates reservation and cannot later publish ready even if blocking read returns. Adapter abort/failure permanently latches original-attempt failure for that session, emits only safe metadata, never retries original after model starts. Reconnect returns same known original; missing after restart is explicit. Elaborate a final acknowledgment/failure contract such that lost/late replies cannot create misleading complete coverage. Existing sessions only explicit fromNow; root changes never overwrite original.
- Capture non-atomic: secure per-file before/after checks plus bounded inventory/metadata revalidation; observed drift => incomplete with persistent baseline coverage gaps; no transactional claim. An incomplete original never becomes complete by comparing later. Preserve verified subset, report unknown coverage.
- Retention: browser close/reload/reconnect and normal OMP exit do not clear. New OMP identity distinct record; switching back reuses original; terminal incarnation replacement/removal/workspace terminal destruction/server shutdown release. Agent-status remove_terminal is NOT by itself valid deletion signal. No silent eviction/rebaseline on quota pressure.
- Defaults grounded in measurement 4,019 names/51,778,033 bytes: 10,000 manifest entries, 2MiB admitted raw file, 128MiB baseline raw storage, 512MiB global accounted snapshot/current storage, max32 retained records, 2 global blocking scan permits, one in flight per identity. Finalize bounded manifest metadata/path bytes, JSON/response pagination and text line/long-line/diff cost/deadline limits; resource pressure refuses new capture or marks incomplete, not original eviction. Runtime benchmarks remain implementation gates. Avoid pretending timeout on spawn_blocking kills I/O; cooperative publication/cancellation and held permits must remain bounded.
- Comparison: immutable baseline ID and server epoch; monotonic decimal-string comparison revision; manual/settled refresh, pinned list/detail revision, stale detail returns typed refresh-required instead of mixing current bytes with old counts. Store bounded current revision or verify reread digest before response, explicitly choose. Old response cannot replace newer view; file absent versus empty distinguishable. Binary/non-UTF8/oversize/read failures and mode-only changes visible with honest null counts where unsupported. Renames can be delete+add; no expensive attribution algorithm.
- Settled signals use existing adapter 250ms handleSettledEnd, not raw agent_end/idle-only heuristic. Continuing/retry/compaction do not trigger. All settled outcomes can have edits. Producer controls may advance metadata/compare server-side; UI listens existing semantic row updates as invalidation hints and performs authoritative read/refresh on open/reconnect. No new general websocket scheduler/event framework. Specify dedup by exact session/turn identity and behavior while hidden.
- UI: owner-bound feature client/query modules using current ApiClient/connections/profileQueryKey. Dedicated capability-free read-only Monaco component/list; reuse renderer patterns but do not import mutating GitLocalChanges/DiffViewer behavior. URI encodes complete owner/baseline/revision/path/side identity; dispose safely. Show session-start vs from-now origin, timestamp, capture/current coverage, shared worktree disclaimer and missing/restart/capacity states. Existing local Git Changes remains distinct.

Parent chain includes PaneContainer; freeze exact integration files by reading current imports before authoring. One host above responsive shell selection; xterm TerminalKeepAliveHost lifetime untouched. Use existing modal/dialog/panel arbitration, focus restore, no key leakage.
