## Scenario/check procedure details

### A. Dirty-start and raw-byte semantics (AC1–3)

1. Initialize isolated real Git repo. Commit base text, then dirty tracked text to `original dirty\r\n`, create eligible untracked text, missing tracked file, present empty text and ignored fixture. Capture acknowledged original; hash exact dirty/untracked bytes and baseline ID.
2. With no edits, known text rows absent; ignored fixture excluded and scope disclaimer accurate. Modify existing, create eligible new, delete original untracked, replace empty with absent and absent with empty. Assert raw original/current sides, presence, counts and EOF-newline distinction.
3. Stage and commit fixtures *as setup actions*, not feature behavior. Original baseline ID/bytes stay identical; union inventory preserves original membership even if index/ignore changes. Return known content to original => no net content row; mode differences remain modeOnly where supported.
4. Add binary NUL, invalid UTF-8, >2MiB, >20k lines, >16KiB long line, unreadable/special/symlink/gitlink/nested repo. Check exact reasons/null counts, no follow, no fabricated content/addition/deletion; incomplete inventory unknown originals remain unknown. Permission tests use actual supported nonprivileged conditions; an ineffective chmod under root is not unreadability proof.

5. Capture namespace presence metadata only, with complete child-set certificates and opaque ignored/pruned prefixes under shared10k-node/8MiB/depth64 cap. `secret.txt` present-but-ignored then unignored/force-added => original unknown/provenance excludedAtCapture, no added row/full counts; a truly absent eligible sibling under certified parent => absentInVerifiedDirectory/known added. Truncated parent or pruned ignored subtree => unknown; no ignored content reads, no whole eligible-list absence inference. Exercise directory drift invalidating the proof and verify budget counters/operations, not source-text/import assertions.
6. Valid fromNow ready/incomplete states have acknowledgment:notApplicable and explicit user intent/no first-turn claim; valid sessionStart ready/incomplete has received. Rust/TS/shared vector tests reject fromNow+received, sessionStart-ready+notApplicable and null-origin ready. UI/router/client behavior must accept the legitimate fallback and show provenance gaps.

### B. Ownership, current revision and async races (AC2/4/5)

1. Two profiles contain same terminal public ID but different roots/bytes; generation changes while request pending. Query key/model URI includes full owner, incarnation, session, root, epoch, baseline, revision and side. Old owner response must not update new panel/models.
2. Freeze current revision R and request detail. Edit disk without refresh: detail remains stored R bytes/counts, not newer mutable disk. Publish R+1 while R response pending: reject old response with refreshRequired or frontend sequence fence; no list/content mixing.
3. New/fork identity gets distinct original; resumed known identity returns original; resumed/initial-history missing identity never auto-captures. Switch root under same identity => rootMismatch and original retained. Root `*`, traversal, unknown/escaped target and ambiguous untargeted cwd => tracking unavailable, terminal still usable.
4. Browser close/reload/reconnect preserves server baseline, while UI source caches/models disposed. Normal process exit/status remove retains until actual terminal metadata removal; existing60s TTL unchanged. Explicit removal, TTL metadata removal, winning incarnation replacement, workspace destruction and server shutdown release exact identity. Stale cleanup/failed removal cannot erase replacement/original respectively.
5. Restart server with persisted terminal replay: old epoch/baseline explicitly missing; reconnect/resume does not capture replacement original. User explicit from-now creates new ID+origin, never overwrites known original. State selector still supports exited-but-retained sessions without semantic row.

### C. Fail-open readiness and late publication (AC7)

1. Actual awaited root-interactive start/switch: server prepares private immutable bytes; producer receives prepared nonce while live, sends activation, receives exact activation receipt while live **before first turn**; producer receipt submission permits public ready/incomplete. No filesystem read on activate/receipt. Child/headless contexts do not prepare originals.
2. Delay prepare delivery until adapter12s deadline and upstream30s fail-open; wall clock shifted forwards/backwards. Server may never publish ready without exact live producer receipt; abort invalidates local token before any late Promise callback. An already-expired accepted reservation cannot publish PREPARED when blocking read eventually returns.
3. Delay activation response past hook lifetime: no final producer receipt, public remains initializing then expires unavailable. Lost prepare or activation response fails original permanently, no automatic retry. Lost final receipt submission response may leave public pending/ready for **same already-acknowledged pre-turn bytes**; reconcile exact receipt only, no recapture.
4. Race fail, session switch, credential revocation, incarnation replacement and blocking completion. Failure tombstone dominates pending activation, no late ready resurrection; held blocking permits/accounting remain bounded until task actually exits.
5. Hook throws/times out, adapter missing/unsupported, collector denies auth or storage capacity full: terminal/model remains usable, UI unavailable/incomplete/missing, never claims complete tracking. `before_agent_start` checks identity/failure only; cannot recapture after user/model turn begins.
6. Actual capture drift during inventory/read/revalidation yields permanent original gaps. Later stable refresh cannot repair/upgrade original. Compare/prepare deadlines are cooperative bounds, not kill guarantees for blocking filesystem I/O.

### D. Settled turns and visible UI (AC7/8)

1. Real OMP tool turn changes synthetic files. Existing250ms settled callback controls refresh for completed, blocked, error, aborted/unknown outcomes. Continuing/retry/compaction do not settle; duplicate exact turn controls coalesce.
2. Panel hidden: producer can update bounded server revision, UI fetches no source/models; on open/reconnect authoritative status+refresh recovers missed semantic hints. Manual refresh sees concurrent editor changes; shared-worktree warning visible, no authorship/task-success inference.
3. Traditional split panes desktop action and compact accessory action open correct pane; alternate runtime desktop/accessory paths work. One host above shell choice; resize/navigation does not remount xterm. Inline/split view correct real Monaco content, selection/focus/accessibility and44px compact targets.
4. Existing projects/runtime sheets/accessory panels/conflict/rename/diagnostics do not compete for focus trap. Escape closes review only; no typed keys leak into PTY/workspace shortcuts; restore invoker without suppressed native keyboard. No viewer save/stage/commit/undo affordance.

5. After failed original, create explicit authenticated fromNow, hide panel and make settled OMP edit. One private500ms /lookup at existing preflight/settled adopts exact current epoch/incarnation/session/root/fromNow ID with notApplicable; next settled refresh updates hidden server revision. Original failure latch stays failed; no capture/poller. Delayed original fail/settled/lookup frames cannot invalidate new fromNow or clear its origin. Lookup timeout/denial leaves open/manual reconciliation, not retry loop.

### E. Resource/security denial and rollback (AC2/4–7)

- Exercise S1 direct canonical root preflight limits before inventory: one requested root only, path4KiB/64 components, <=128 metadata operations/64KiB scratch/1s inside overall deadline, untargeted candidate bounds, shared permits. Wide/deep/unrelated trees do not cause discovery/status work or unbounded allocations; observe filesystem-operation counters and response denial, not source-string assertions.
- Exercise all S8 hard defaults, including bounded namespace certificates/provenance gaps, with reduced-limit unit fixtures and representative runtime measurement. Include metadata/path allocation and escaped JSON worst case, not only raw disk size. Candidate+old read leases count globally. No silent oldest-record eviction; capacity retains original and old current timestamp.
- Two scan permits and one/key held until true closure exit; no queue explosion or detached retry accumulation. Bounded32 records,10k entries,512MiB global accounting,1e6 diff work and50ms cooperative per-file checks. Detail leases/concurrency/expiry prevent unbounded old revisions.
- Auth denial on public source endpoints; private bearer only on same-loopback Host/peer route; normal account policy unchanged. Verify private-no-store headers including errors, body/page/detail byte limits, no source/token/prompt/transcript in logs/status/URLs/evidence except explicit synthetic qualification source.
- Temp material out of worktree and owner-private; no-follow ancestor/final swap defenses reused. Destruction releases files/accounting. Coherent feature rollback removes host/channels/producer protocol/routes/domain and restores owned managed adapter; no user worktree/index/branch mutation or DB migration.
