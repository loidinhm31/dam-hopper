## Fixture and journey scenarios
1. Disposable main project, nested-project mapping and nested Git repository; separate non-Git directory, empty repo, shallow clone and detached checkout. Bare remote plus independent peer clone; no network/credentials required for bare remote.
2. Deterministic linear/merge/octopus graph with skewed commit dates and explicit missing/off-page parent cases; remote/local same display branch name. External git derives expected OIDs/parents; graph unit test synthetic OIDs are separate algorithm boundary coverage.
3. Dirty staged/unstaged/untracked files, binary/empty/deleted/renamed paths; worktree paths with approved punctuation. Capture raw byte digests and index binary diff before each action, not only after all actions.
4. Active and inactive rewrite targets with descendants, merge-ineligible descendants, linked worktree occupancy; test-only deterministic signed commit headers may use git hash-object without signing dependency and independently assert server consent guard/removal. No fake receipt fixtures for real acceptance.
5. Conflict fixture via independently invoked Git merge/cherry-pick; server GET operation/conflicts confirms state; user guidance and read-only presentation tested, never resolve it by incompatible UI.
6. Delays/drop-ack via runner-owned transparent test proxy to unchanged current server. Complete app request is forwarded once, response withheld/disconnected, authoritative Git records reveal outcome. Proxy must not turn any failed operation into success. Unit race fixtures can test precise callback ordering, but integrated AC08 still required.
7. Authenticated real root setup uses existing application_e2e_seed helper for isolated SQLite account and valid signed session, secure profile bootstrap + server auth refresh for verified account, then visible root profile/project UI; no arbitrary fabricated AuthStatus or synthetic account. Debug loopback via adb reverse, no-auth cannot satisfy account/auth/root qualification. Seed helper must be prebuilt from current source; runner never builds/installs it implicitly. Keep tokens out of logged argv/screenshots; use protected runner file/arguments and redacted reports.

## Non-goals and invariants
No server/packages/ui writes; endpoints/fields/dependency upgrades; API29 downgrade; WebView/local Git; all-disconnected graph; profile-wide/bulk Git page; dormant 12-panel cutover; new services/schedulers/feature flags; offline queue/retry; editable diff drafts/hunk discard; native conflict editor/continue/abort; blame parity; auth/terminal redesign or shortcut expansion.
Retained editor sole editable authority. Owner/target/root/checked-out/viewed identities remain distinct. Old PTYs never moved/killed/recreated by switch/rebind. Rebind retains controller/grid/replay offset and documents/undo, not merely IDs. Missing verified account blocks authority.
