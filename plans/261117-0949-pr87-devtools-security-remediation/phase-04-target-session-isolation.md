## Architecture / steps — enforce-owned-target-sessions
1. Replace foreign-target blacklist with bounded per-connection positive child-session/correlation state, grounded in Phase 02 instance ownership snapshot and this socket's causal attachments. Root native target pre-authorized only for bound live logical/incarnation identity. Distinguish Unknown/Pending/Owned/Foreign/Detached; unknown cannot transition merely because client requests attach or supplies targetId.
2. Validate every envelope's sessionId before method policy; target parameters (including Target.getTargetInfo) identify owned target. Missing target uses known root semantics only, not arbitrary fallback. Deny foreign queries with uniform errors revealing no existence. Preserve download/Browser/Input-accounting/ServiceWorker restrictions on owned children too: target ownership never authorizes nonlocal effects.
3. Enumerate supported Target methods/parameter effects (discovery/getTargetInfo/attachToTarget/setAutoAttach/autoAttachRelated/detachFromTarget/filters). Deny instance-wide related-target/browser-context/lifecycle or unknown routing methods even for holder. Root auto-attach only with deployed scope guarantee AND positive causal parentage; never trust client filters. Separately enforce Phase 01 ServiceWorker policy: default-deny all commands and suppress all events/results absent proven enforceable target scope; context-wide stopAllWorkers and analogous lifecycle remain denied unconditionally. An owned service-worker Target attachment does not establish a scoped ServiceWorker domain contract.
4. Correlate bounded pending request IDs for every response with target/session metadata (getTargetInfo, attach and supported discovery). Check response target info/session owner before returning it; unknown/colliding/oversized correlation state closes/rejects, never passthrough. Return response correlated to original CDP id/session on denied native result without exposing foreign metadata. Suppress legacy nested receivedMessageFromTarget as transport tunnel, not recursively unvalidated forwarding.
5. Filter targetCreated/targetInfoChanged/targetDestroyed/targetCrashed, attachedToTarget/detachedFromTarget, flattened events/responses and future known target-bearing routes. Include worker, shared_worker, service_worker, iframe, page, browser_ui, browser and unknown types; type does not grant ownership. Unknown target metadata is suppressed before forwarding any wrapper, even if it embeds an apparently valid child session.
   ServiceWorker.workerRegistrationUpdated/workerVersionUpdated/workerErrorReported and any deployed ServiceWorker events are a distinct suppression path, including script/scope URLs, registration/version/target/client IDs embedded in arrays or payloads without envelope targetId/sessionId. Correlated replies cannot forward context registries from a denied/unknown request. Implement any narrowly proven exception by validating the complete payload and effect scope BEFORE forwarding, not by dropping only foreign Target events. Apply Phase 01 analogous-domain inventory to direct commands/results/events; unknown nonlocal scope denies. No broad unrelated protocol redesign.
6. Process attach response/event internally before forwarding; quarantine candidate child until positive provenance complete. Owned OOPIF/dedicated worker requires proven live owned-parent chain and exclusive relation; do not infer exclusivity for shared/service workers from attachment alone. If missing, foreign or ambiguous: deny/suppress and detach captured unowned connection without exposing metadata, resuming unknown paused code or closing another target. Prevent auto-attach from pausing unrelated targets; `waitForDebuggerOnStart` cannot become an availability attack.
7. Every child command/event revalidates live ownership and Phase 03 control epoch. Revoke/detach/retire/gap/overflow removes or invalidates dependent session facts before reuse; stale IDs on another connection/incarnation stay denied. Bound targets, pending requests, sessions, nested-envelope handling and payload allocation; cap exhaustion closes/denies rather than clear-and-allow. Do not allocate full metadata clones for dropped messages.
8. Tests independently establish B dedicated/shared/service workers; A actual proxy attempts Target discovery/query/attach AND ServiceWorker enable/inspection/lifecycle, including stopAllWorkers, stopWorker, unregister and update/start variants. B registration/version/script/client metadata must be absent and live worker must still answer an independently held channel after every lifecycle attempt. Registering the fixture before A subscription prevents an empty-event pass; trigger further worker/version activity to exercise suppression. Positive owned worker/OOPIF and real frontend Console/Network/Elements/Issues remain required Phase 05 gates; deployed unsupported fixture means missing evidence, not success.
