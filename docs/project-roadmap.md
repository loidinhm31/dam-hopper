## Retired scope

<a id="trusted-plugin-platform-2026-09-22"></a>

The DamHopper trusted plugin platform, plugin SDK/runner, plugin APIs, plugin host bridge, and plugin release assets are permanently retired. `Agent Store` distribution remains a separate product area. Former specifications and removal procedures are documented in the [Retired Plugin Platform Archive Record](./archive/retired-plugin-platform.md).
