<a id="tauri-desktop-and-ssh-forwarding-2026-11-02"></a>

### Tauri desktop host and desktop SSH port forwarding (2026-11-02)

The Tauri 2 desktop application host (`apps/native`), desktop release workflows, desktop SSH port forwarding UI and runtime, and native child WebView debug host are permanently retired under Phase 02 (P0a) of the AI Dev OS redesign. DamHopper is now a web-first development environment with standalone Linux/Windows server daemons and an independent Android companion app (`native/android-app`). Remote Git SSH operations remain supported through server APIs and UI retry helpers.

<a id="usage-telemetry-retirement-2026-11-02"></a>

### Usage analytics, telemetry runtime, and OTLP collector (2026-11-02)

Telemetry runtime, OTLP collector listener, usage REST endpoints (`/api/usage/*`), client usage dashboards and insight settings, and mobile usage monitoring are permanently retired under Phase 03 (P0b) of the AI Dev OS redesign. Host resource metrics (CPU, memory, disk, network, system uptime) and traditional terminal usage-mode remain fully supported. Legacy `server.telemetry` TOML configurations and PUT `/api/config` payloads are gracefully tolerated without error.

<a id="legacy-web-shells-and-mobile-paths-2026-11-03"></a>

### Legacy web shells, workspace modes, and web mobile policy (2026-11-03)

Legacy web shells (`WorkspacePage`, `DashboardPage`, `IdeShell`, `TerminalWorkspaceShell`, `MobileWorkspaceShell`, `AppLayout`, `TopNav`), workspace-mode toggles, floating tool/file panel controllers, and browser-specific mobile keyboard/coarse-pointer policies are permanently retired under Phase 08 of the AI Dev OS redesign. Root `/` now boots `OsShell` directly. Generic terminal input suppression (Cognito, disconnect, frame-focus gating) is preserved via `terminal-input-policy.ts`. Native Android app architecture (`native/android-app/`) remains independent and unaffected.
